## Отчет о проделанной работе (Версия 2.0.0)

### Что нового:
- **Иерархическая система папок:** поддержка неограниченной вложенности подпапок, раскрытие и сворачивание в виде плавного аккордеона, закрепление избранных папок, персонализация цвета и значка.
- **Кнопка быстрого добавления «Карандаш» в папках:** создание заметки или задачи напрямую внутри выбранной папки в один клик.
- **Интеллектуальный выбор типа записи:** при создании из общего экрана открывается удобный диалог выбора между новой заметкой и задачей с дедлайном.
- **Системная папка «Календарь»:** автоматическое сохранение всех событий, заметок и дедлайнов, созданных в календаре, с наименьшим приоритетом расположения (всегда внизу списка).
- **Экран «Календарь» с табличной сеткой:** аккуратное центрированное табличное представление дней месяца с ровными рядами недель.
- **Индикация событий и дедлайнов в календаре:** подсветка дней цветными маркерами-точками (синий для событий, красный для задач с дедлайном) с сохранением видимости при выборе дня.
- **Настройка цветов маркеров:** возможность выбрать индивидуальные цвета для событий и дедлайнов в настройках приложения.
- **Удаление записей прямо из календаря:** кнопки корзины в карточке выбранного дня для быстрого удаления событий, дедлайнов и заметок без перехода в другие разделы.
- **Новое меню быстрого действия (FAB):** выдвижное меню для создания заметки, задачи или папки с корректной послойной обработкой нажатий и закрытием по клику вне области.
- **Дизайн-система векторных иконок `CupertinoIcon`:** библиотека строгих векторных SVG/Ionicons иконок (карандаш, папка, документ, календарь, булавка и др.) взамен устаревших текстовых эмодзи.

### Изменено:
- **Редизайн пользовательского интерфейса (Cupertino Glass):** обновлены карточки, типографика, плашки, отступы и цветовая палитра в стилистике iOS / Cupertino с поддержкой тёмной и светлой тем.
- **Шапка экрана заметок и задач:** реализован полноширинный сегментированный контроллер («Все | Заметки | Задачи») с идеальным распределением по ширине экрана.
- **Сенсорная архитектура карточек и папок:** кликабельные области разделены на независимые элементы, исключающие взаимную блокировку нажатий и ошибки обработчиков жестов.
- **Надёжность сохранения данных:** методы `saveNote`, `saveTodo`, `deleteNote`, `deleteTodo` и функции `FoldersContext` переведены на функциональные обновления стейта (`prev => ...`), устраняя рассинхронизацию данных.
- **Мгновенное удаление в один клик:** удаление папок, заметок и задач происходит мгновенно без блокирующих системных окон и предупреждений. При удалении папки все вложенные материалы безопасно сохраняются в общем списке.
- **Модуль расписания и уведомлений:** устранены циклические зависимости в сервисе уведомлений, обновлена типизация занятий `Lesson` и расчёт временных слотов.
- **Версионирование и синхронизация:** актуализирована версия приложения до `2.0.0` (сборка 5) с централизованным источником правды `APP_VERSION`.

### Удалено:
- Значок шестерёнки настроек из правого верхнего угла экрана (доступ к настройкам вынесен в нижнюю панель навигации).
- Кнопка «+ Папка» из верхней панели заметок (создание перенесено в меню FAB и панель действий папки).
- Браузерные диалоги подтверждения `window.confirm` и нативные алерты с адресом `localhost:8081`.
- Неиспользуемые устаревшие файлы и сервисы (`EditScreenInfo.tsx`, дублирующие модули уведомлений).
- Сырые текстовые эмодзи в интерфейсе (полная замена на векторную графику).

## Функциональность

* **Заметки и задачи:** создание текстовых заметок, списков дел с дедлайнами и вложенных проектов.
* **Папки и структура:** организация записей по проектам и категориям с цветовой дифференциацией.
* **Календарь и дедлайны:** интерактивный обзор запланированных дел, занятий и сроков сдачи работ.
* **Расписание:** недельное расписание занятий с поддержкой числителя и знаменателя (1-я и 2-я недели).
* **Оформление:** адаптивная тёмная и светлая темы интерфейса Cupertino Glass.
* **Автономность:** безопасное локальное хранение всех пользовательских данных через AsyncStorage без обязательного подключения к сети.

## Установка и запуск

### Запуск в режиме разработки:
```bash
# Установка зависимостей
npm install

# Запуск в веб-браузере
npm run web

# Запуск для Android
npm run android
```

### Установка готового APK на Android:
1. Перейдите в раздел [Releases](https://github.com/aevoro/SNotes/releases).
2. Загрузите установочный файл **SNotes.apk** версии `2.0.0`.
3. Установите приложение на мобильное устройство.
