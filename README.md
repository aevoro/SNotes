## О проекте

**SNotes** объединяет три ключевых инструмента повседневной продуктивности — **заметки**, **задачи с дедлайнами** и **календарное расписание** — в едином лаконичном интерфейсе, вдохновленном эстетикой Apple iOS (Cupertino Glass). 

Приложение спроектировано для максимального удобства студентов, школьников и специалистов, которым требуется держать учебу, проекты и личные дела в идеальном порядке без перегруженности лишними функциями.

## Ключевые возможности

### 📂 Иерархическая структура и папки
- Поддержка вложенных папок и подпапок с плавным аккордеонным раскрытием.
- Персонализация каждой папки: выбор акцентного цвета и уникальной иконки.
- Закрепление важных папок вверху списка для мгновенного доступа.
- Кнопка быстрого добавления «Карандаш» — создание заметки или задачи напрямую внутри нужной папки.
- Системная папка «Календарь» для автоматической группировки событий и дедлайнов.

### 📝 Заметки и умные списки задач
- Разделение на общие записи, текстовые заметки и списки дел с дедлайнами через полноширинный сегментированный переключатель.
- Чекбоксы выполнения задач с зачеркиванием и визуальной обратной связью.
- Быстрое контекстное меню создания (FAB) для мгновенной фиксации идей.
- Мгновенное удаление записей в один клик без блокирующих всплывающих окон.

### 🗓 Интерактивный календарь и дедлайны
- Точная табличная сетка дней месяца со строгим выравниванием колонок по дням недели.
- Цветные маркеры-точки под числами: синие для персональных событий, красные для дедлайнов задач.
- Автоматическая адаптация контраста точек при выборе дня.
- Модальное окно выбранного дня с компактными карточками событий, возможностью быстрого добавления и удаления записей на лету.
- Полная кастомизация цветов маркеров в настройках приложения.

### 🎓 Академическое расписание
- Недельное расписание занятий с поддержкой числителя и знаменателя (автоматическое чередование 1-й и 2-й учебных недель).
- Указание времени пар, номеров аудиторий, типов занятий и корпусов.
- Удобный таймлайн дня с привязкой текущего времени.

### 🎨 Дизайн Cupertino Glass и нативный SVG
- Адаптивные темы: глубокая тёмная (`Dark`) и кристально чистая светлая (`Light`).
- Собственная библиотека векторных иконок на базе `react-native-svg` — отсутствие задержек загрузки шрифтов, идеальная четкость на любых плотностях экранов и 100% совместимость с Android и Web.
- Тонкие полупрозрачные разделители, акцентные плашки и сглаженные скругления углов.

### 🔒 Автономность и приватность
- Все данные хранятся исключительно на устройстве пользователя через локальное хранилище `AsyncStorage`.
- Никакой обязательной регистрации, синхронизации со сторонними серверами, трекеров и рекламы. Приложение полностью работоспособно в оффлайн-режиме.

## Стек технологий

* **Целевые платформы:** Android (APK / AAB), Web (PWA / SPA), iOS
* **Фреймворк:** [React Native](https://reactnative.dev/) / [Expo SDK 52](https://expo.dev/)
* **Язык программирования:** TypeScript (Strict Mode)
* **Маршрутизация:** [Expo Router v4](https://docs.expo.dev/router/introduction/) (File-based navigation)
* **Векторная графика:** [react-native-svg](https://github.com/software-mansion/react-native-svg) (Cupertino SVG Icon Pack)
* **Локальное хранилище:** [@react-native-async-storage/async-storage](https://github.com/react-native-async-storage/async-storage)
* **Сборка и CI/CD:** GitHub Actions (автоматизированная компиляция Release APK)

## Установка и запуск

### Запуск в режиме разработки:

```bash
# 1. Клонирование репозитория
git clone https://github.com/aevoro/SNotes.git
cd SNotes

# 2. Установка зависимостей
npm install

# 3. Запуск веб-версии
npm run web

# 4. Запуск для Android (эмулятор или подключенное устройство)
npm run android
```

### Установка готового приложения на Android:
1. Перейдите в раздел [Releases](https://github.com/aevoro/SNotes/releases) или скачайте артефакт из последней успешной сборки в [GitHub Actions](https://github.com/aevoro/SNotes/actions).
2. Загрузите установочный файл **SNotes.apk** актуальной версии.
3. Разрешите установку из неизвестных источников в настройках устройства и установите APK.
