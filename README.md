## Функциональность

* **Заметки:** Создание, редактирование и быстрый поиск учебных записей.
* **Расписание занятий:** Недельная сетка пар с поддержкой переключения между 1-й и 2-й учебными неделями.
* **Список задач:** Учет дедлайнов, лабораторных и практических работ.
* **Оформление:** Поддержка светлой и тёмной тем интерфейса через ThemeContext.
* **Автономность:** Локальное хранение всех пользовательских данных на Android-устройстве без обязательного подключения к сети.

## Установка на Android

Для использования приложения на смартфоне компиляция исходного кода не требуется:

1. Откройте раздел [Releases](https://github.com/aevoroo/SNotes/releases).
2. Загрузите установочный файл **SNotes.apk** последней версии.
3. Запустите файл на вашем Android-устройстве и подтвердите установку.
